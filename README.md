# 高途课堂兼容修复

适配高途学生端 `11.12.3.0722`，不修改 Windows 音频设置，也不修改高途原始签名 DLL。

## 使用

双击 `高途兼容修复.exe`。程序会自动启动高途并保持兼容层运行。

- `384 kHz 兼容`始终启用，用于避免课堂音频回调的固定栈缓冲区溢出。
- `阻止高途触发音频闪避`默认开启。它只移除高途子进程的通信音频标记，避免其他程序音量被压低。
- 更改音频闪避开关后，点击`应用设置并启动高途`，程序会安全重启高途并应用新设置。
- 高途运行期间需要保持本程序开启。退出本程序时会同时退出高途。

## 安全边界

程序启动前会校验 `libShijieRoom.dll` 的 SHA-256。若高途升级导致 DLL 变化，程序会停止应用兼容逻辑并提示重新适配，避免把当前版本的函数地址用于未知版本。
